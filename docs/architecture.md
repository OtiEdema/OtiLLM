# OtiLLM v2.0 Architecture

OtiLLM v2.0 is a governed cognitive runtime architecture for evidence-aware, policy-constrained and traceable LLM systems.

The formal architecture jointly represents evidence state, evidence sufficiency, contradiction, governance risk, uncertainty, memory state, policy state, operational cost and provenance. The publication manuscript distinguishes this formal specification from the subset currently implemented and empirically evaluated.

For the JAIR rebuild, the authoritative implementation-status boundary is:

`experiments/jair_v2_rebuild/IMPLEMENTATION_STATUS.md`

Architectural mechanisms must not be described as empirically demonstrated unless they are executable in the frozen publication release and covered by the archived evaluation.
